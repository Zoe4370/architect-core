# Mission Architect

A browser-based space mission design game, built for the NASA Space Apps Challenge 2026.
Assemble a spacecraft under hard limits of budget, mass, power and downlink, launch it,
and find out why it succeeded or failed.

## Features

- 3 scored missions plus a free Sandbox
- Rookie / Standard / Veteran flight rules, random events and unexpected constraints
- Solo, Co-op crew (up to 4 players, pass-and-play) and Versus (2-4 teams) modes
- Live 3D spacecraft and trajectory viewers (react-three-fiber)
- Mission dashboard with resource telemetry playback
- Rankings, saved designs, side-by-side compare, share codes and links
- Post-mission analysis and a downloadable results card

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Netlify

Connect this repo in Netlify. The settings are read from `netlify.toml`
(build command `npm run build`, publish directory `dist`).

Or drag and drop: run `npm run build`, then drop the `dist` folder on https://app.netlify.com/drop

## Data sources

Figures are modeled on NASA Launch Services Program payload planners, the PDS archive,
the NASA RPS program and the GMAT scenario library.

## Super Intelligence (SI) disclosure

This project was built with the help of an AI assistant, under the
direction of the team. SI was used for:

- **Code:** writing and debugging the React / three.js application in `src/MissionArchitect.tsx`
- **Writing:** interface copy, mission descriptions and this documentation

No images, video or audio were generated by an SI model. The app uses no NASA logos, flags or
mission patches. Instrument, vehicle and mission figures are approximations modeled on the
public sources named in the interface, entered by hand, not pulled live from NASA datasets.
